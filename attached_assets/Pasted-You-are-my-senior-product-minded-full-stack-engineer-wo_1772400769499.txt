------------------------------------------------
PHASE 1 — PDF Output Specification (must implement)
------------------------------------------------

A) Cover Page (1 page)
- Title (user-editable; default: “Student Learning Summary”)
- Student name
- Date range
- Generated date
- Minimal footer “Generated with {AppName}” (small)

B) Summary Page (1 page max)
Include:
- Total lessons logged (count)
- Total time logged (hours + minutes)
- Evidence items included (count) if evidence included
- Subject breakdown table:
  - Subject | Lessons | Time (hh:mm)

C) Chronological Learning Log (main body)
- Group by Month → within month list entries chronologically
- Each lesson entry format:
  - Date — Subject (Duration)
  - Title (optional, smaller)
  - Notes (optional; wrap nicely; clamp very long notes with “(continued…)” if needed)
  - Evidence section directly under entry (if included):
    - Thumbnails embedded (not separate dump at end)
    - Max 4 images per lesson by default
    - Skip non-image evidence (PDF/doc) or include as file name/link line

D) Optional Monthly Totals (toggle)
At end of each month, show:
- Lessons count
- Total time
- Top subjects (optional)

E) Export Options (in UI)
- Include Summary page (default ON)
- Include lesson details (default ON)
- Include evidence thumbnails (default ON)
- Include full-size images (default OFF; only if feasible)
- Monthly totals page (default OFF)

F) Print-friendly requirements
- Black-and-white compatible
- No heavy backgrounds
- Good whitespace and consistent typography scale
- Page numbers on footer from page 2 onward

G) Safety limits
- Warn and/or enforce:
  - Max lessons per export (e.g., 500) with message suggesting splitting
  - Max embedded images (e.g., 100) OR max total image bytes
- Compress images for embedding (if possible)
- Ensure PDF file size stays reasonable (target < 20–40MB)
