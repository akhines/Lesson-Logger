PHASE 1 — User Reminder Preferences

Add a ReminderSettings model (or extend existing UserSettings):

Fields:
- userId (unique)
- dailyReminderEnabled (boolean)
- dailyReminderTime (time, user local timezone)
- weeklySummaryEnabled (boolean)
- weeklySummaryDay (0–6)
- weeklySummaryTime (time)
- timezone (string, e.g., "America/New_York")
- createdAt
- updatedAt

Default:
- All reminders OFF by default.

Add UI under:
Settings → Reminders

UI Requirements:
- Toggle: “Daily reminder to log learning”
  - Time picker
- Toggle: “Weekly summary”
  - Day picker (Sun–Sat)
  - Time picker
- Calm explanatory copy:
  - “Get a gentle nudge if you haven’t logged today.”
  - “Receive a weekly summary of your logged learning.”

Save preferences immediately.

PHASE 2 — Reminder Logic (Daily)

Implement a scheduled job (using existing cron/background pattern).

Daily Reminder Logic:
For each user where:
- dailyReminderEnabled = true
- Current time >= user.dailyReminderTime in user.timezone
- AND user has NOT logged a lesson today

Then send reminder email.

Email content:
Subject: “Want to log today’s learning?”
Body:
- Friendly greeting
- One sentence encouragement
- Primary button: “Log Today” (deep link to dashboard + auto-open Quick Log if supported)
- Secondary link: “View Dashboard”

Rules:
- Only send once per day max.
- Track lastReminderSentAt to prevent duplicates.

PHASE 3 — Weekly Summary Email

If:
- weeklySummaryEnabled = true
- Today = weeklySummaryDay
- Current time >= weeklySummaryTime
- User has at least 1 lesson in past 7 days

Then send weekly summary email.

Weekly Summary should include:
- Total minutes logged
- Number of lessons
- Subjects covered (list)
- Evidence count
- Button: “View Portfolio”
- Button: “Generate Export”

No shame language. Avoid “You missed days.”

Implement:
