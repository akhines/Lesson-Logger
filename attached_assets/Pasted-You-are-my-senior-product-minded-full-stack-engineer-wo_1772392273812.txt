PHASE 1 — Data Model

Create a ShareLink model/table:

Fields:
- id (uuid)
- token (random, unique, URL-safe string, 32–48 chars)
- userId (owner)
- studentId (required)
- startDate (nullable)
- endDate (nullable)
- passwordHash (nullable)
- expiresAt (nullable)
- allowDownload (boolean default true)
- createdAt
- updatedAt
- revokedAt (nullable)

Indexes:
- token (unique)
- studentId

Constraints:
- Must validate student belongs to user at creation.

Add “Share” button in Portfolio view (near Export button).

Clicking opens Share modal with options:

Options:
- Date range:
  - Current view (default)
  - Custom range
- Expiration:
  - Never
  - 7 days
  - 30 days
  - Custom date
- Password protect (optional checkbox)
- Allow downloads (on/off)

Primary button:
- “Create Share Link”

After creation:
- Show generated URL
- “Copy link” button
- Show password (if created) one time
- Link to “Manage share links”

PHASE 3 — Public Share Route

Implement public route:
- /share/[token]

Behavior:
1) Lookup ShareLink by token
2) If revoked → show “This link is no longer active.”
3) If expired → show “This link has expired.”
4) If password required:
   - Show password form
   - Validate against passwordHash
   - Store temporary session cookie for this token

5) Fetch lesson logs + evidence for:
   - studentId
   - Within date range (if set)
   - Using same grouping logic as portfolio

Important:
- MUST enforce studentId match
- MUST prevent access to other family data

Render:
- Clean read-only portfolio view
- No edit buttons
- Optional download buttons if allowDownload = true

Branding:
- Minimal header
- Student name
- Date range
- “Shared portfolio” title
- No state-specific language

PHASE 4 — Evidence Access Security
